# تطبيق الطلبات (الحقيقي)

نفس واجهة نموذج «سنا»، لكنها مربوطة بقاعدة البيانات في `firebase/` بدل التخزين في المتصفح. يعني الطلب اللي يرسله العميل من جواله يوصل لجهاز المحل خلال ثوانٍ، وكل تحديث من المحل يوصل للعميل.

صفحتين، ولكل وحدة أيقونة لحالها لما تتثبت:

| الصفحة | لمين | الدخول |
|---|---|---|
| `index.html` | العميل | برقم الجوال ورمز تحقق (SMS) مرة وحدة على الجهاز، ويطلبه التطبيق وقت أول طلب |
| `shop.html` | جهاز المحل | رمز PIN بأزرار كبيرة. بعد 5 محاولات غلط يتقفل 15 دقيقة |

## وش يشتغل

- **القائمة والأسعار والأحياء والمواعيد ورسوم التوصيل** تجي من مستند المحل في قاعدة البيانات. ما فيه أسعار مكتوبة في الكود.
- **العميل:** يطلب استلامًا أو استلامًا سريعًا أو يسلّم في المحل، ويتابع طلبه لحظة بلحظة، ويلغيه قبل القبول، ويشوف أختام الولاء. ويقدر يرسل موقعه للمندوب (اختياري).
- **المحل:** الطلبات الجديدة تظهر فورًا مع صوت (بعد أول ضغطة على الشاشة، لأن المتصفح ما يسمح بالصوت قبلها)، والعدد في عنوان التبويب. وفيه القبول والاعتذار، والجرد، ونقل الطلب خطوة خطوة، والطلب في المحل. ومفاتيح «مفتوح / مواعيد اليوم / التنظيف الجاف» (في تبويب «التشغيل») تظهر للعملاء فورًا، ولما يكون المحل مغلق تظهر «مغلق مؤقتًا» تحت اسمه. وزر «العملاء» فوق يعرض كل عملاء المحل: الاسم والجوال وعدد الطلبات والأختام والاشتراك وآخر طلب، مع بحث بالاسم أو الجوال وزر واتساب.
- **الاشتراك الشهري من المحل:** زر «اشتراك شهري لعميل»، ثلاث خطوات: جوال العميل، ثم الباقة، ثم «استلمت المبلغ · فعّل». يبدأ شهر كامل من اليوم (30 يومًا وكل القطع)، ويظهر للعميل في «بطاقتي» فورًا، والقطع تنخصم تلقائيًا من طلباته في التطبيق والمحل. لو فعّله مرة ثانية يبدأ شهر جديد، والقطع الباقية ما تنتقل.
- **واتساب:** زر في كل طلب يفتح واتساب برسالة جاهزة للعميل حسب حالة الطلب. الموظف يضغط «إرسال» بنفسه.
- **بدون إنترنت:** الصفحات تفتح من النسخة المحفوظة، وFirestore يحتفظ بآخر طلبات.

## وش ما يشتغل للحين

- **الدفع الإلكتروني:** يظهر «قريبًا». كل الطلبات كاش أو شبكة.
- **الاشتراك الشهري من التطبيق:** العميل يشترك من المحل للحين (تحت). الاشتراك من التطبيق يحتاج الدفع الإلكتروني.
- **إشعارات الجوال للعميل** (تحتاج FCM)، و**صفحة سياسة الخصوصية والشروط**.

## التجربة على جهازك

تحتاج Node.js وJava وPython.

```bash
cd firebase && npm run emulators
```

في نافذة ثانية (مرة وحدة بعد كل تشغيل للمحاكي):

```bash
cd firebase && FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 npm run seed
```

وفي نافذة ثالثة:

```bash
python -m http.server 5173 --bind 127.0.0.1 --directory app
```

- العميل: http://localhost:5173 . أي رقم يبدأ بـ 05 يشتغل، ورمز التحقق يظهر تحت الخانة (على جهازك فقط).
- المحل: http://localhost:5173/shop.html ، والرمز `2468` (للمحاكي فقط).

لما الصفحة تشتغل على `localhost` تتصل بالمحاكي تلقائيًا، وعلى أي رابط ثاني تتصل بالمشروع الحقيقي.

## لمحل حقيقي

1. مستند المحل في قاعدة البيانات الحقيقية: الاسم والقائمة والأسعار والأحياء والمواعيد والقواعد، بنفس شكل `firebase/seed/demo-shop.js`. **ما ينحط في هذا المستودع.**
2. في `config.js`: رقم المحل (`SHOP_ID`) وإعدادات مشروع Firebase للويب. هذه الإعدادات عامة بطبيعتها، واللي يحمي البيانات هو `firestore.rules` والدوال.
3. في `manifest.webmanifest`: اسم المحل اللي يظهر تحت الأيقونة.

## الملفات

```
index.html, shop.html   الصفحتان
app.js                  الواجهة كلها (العميل والمحل)
data.js                 كل القراءة والكتابة مع Firebase، في مكان واحد
config.js               أي محل وأي مشروع
app.css                 التصميم
sw.js                   العمل بدون إنترنت
```
