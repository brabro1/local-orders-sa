# الطلبات الرقمية للمحلات المحلية

صفحات طلب على الجوال ولوحات طلبات بسيطة للمحلات المحلية في السعودية، نبدأ بالمغاسل ثم المطاعم.

هذا المستودع فيه **الكود والنماذج فقط**. الخطة والمهام والقرارات في نوشن.

## الروابط

| | |
|---|---|
| **كل النماذج** | https://brabro1.github.io/local-orders-sa/ |
| تطبيق مغسلة «سنا» للجوال (يتثبّت) | https://brabro1.github.io/local-orders-sa/laundry-pwa/ |
| نموذج مغسلة «سنا» | https://brabro1.github.io/local-orders-sa/laundry/ |
| نموذج مطعم «سُفرة الحارة» | https://brabro1.github.io/local-orders-sa/restaurant/ |
| **نوشن:** الخطة، المهام، المحلات، القرارات، سجل العمل | [صفحة المشروع](https://app.notion.com/p/40c3a671129a810981a6d132d605a32f) (تحتاج دعوة) |

الروابط تتحدث تلقائيًا بعد كل دمج في `main`.

**تثبيت التطبيق:** على الآيفون افتح الرابط في Safari، ثم «مشاركة»، ثم «إضافة إلى الشاشة الرئيسية». على الأندرويد افتحه في Chrome، ثم «تثبيت التطبيق». أرقام للتجربة: `0509876543` (مشترك)، `0577778899` (عنده مكافأة ولاء).

كل النماذج **نسخ عرض**: الأسماء والأسعار افتراضية، ولا تُرسل طلبات أو مدفوعات حقيقية.

## التشغيل محليًا

```bash
python scripts/build.py --serve
```

ثم افتح `http://localhost:8765`. نفس الروابط المنشورة، لكن على جهازك.

## طريقة العمل

1. حدّث النسخة المحلية، واقرأ آخر «سجل العمل» في نوشن.
2. فرع لكل تغيير، ثم طلب دمج يراجعه الشريك الآخر. لا نعمل على `main` مباشرة.
3. بعد الدمج: الروابط تتحدث وحدها. حدّث المهمة في نوشن وأضف سطرًا في «سجل العمل».

التفاصيل الكاملة في [`CLAUDE.md`](CLAUDE.md).
