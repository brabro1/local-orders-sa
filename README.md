# الطلبات الرقمية للمحلات المحلية

صفحات طلب على الجوال ولوحات طلبات بسيطة للمحلات المحلية في السعودية، نبدأ بالمغاسل ثم المطاعم.

هذا المستودع فيه نماذج العرض التي نستخدمها في زيارات المحلات، والخطة، وخارطة الطريق. النظام الفعلي لم يُبنَ بعد (انظر [خارطة الطريق](docs/roadmap.md)).

| [`demos/laundry.html`](demos/laundry.html) | نموذج مغسلة «سنا»: واجهة العميل ولوحة المحل |
| [`demos/restaurant.html`](demos/restaurant.html) | نموذج مطعم «سُفرة الحارة»: القائمة بالسعرات، تخصيص الوجبة، الصنف غير المتوفر |

## النماذج

كل نموذج **نسخة عرض**: البيانات والأسعار افتراضية، ولا يرسل طلبات أو مدفوعات حقيقية. البيانات تُحفظ في متصفح الجهاز فقط وتُعاد تلقائيًا بعد 12 ساعة.

في كل نموذج زر **«إعدادات العرض»** لكتابة اسم المحل الذي تزوره، وفيه سيناريو عرض من خمس خطوات، وقائمة بما يعمل فعليًا وما هو محاكاة.

وفي التطبيق نفسه زر ترس ⚙️ لاختيار **اللغة** (عربي أو إنجليزي) و**المظهر** (حسب الجهاز أو فاتح أو داكن). الأسعار تُعرض برمز الريال الرسمي، وشاشة المطبخ في المطعم داكنة دائمًا.

### تشغيلها محليًا

افتح أي ملف `demos/*-site/index.html` في المتصفح مباشرة، أو شغّل خادمًا بسيطًا:

```bash
python -m http.server 8766 --directory demos/restaurant-site
```

ثم افتح `http://localhost:8766` من المتصفح. على شاشة عريضة تظهر واجهة العميل ولوحة المحل جنبًا إلى جنب، وعلى الجوال تبدّل بينهما من الشريط العلوي.

### تعديل نموذج

1. عدّل الملف المصدر `demos/<name>.html` (لا تعدّل النسخ داخل `*-site` يدويًا).
2. ولّد النسخ المستقلة:

   ```bash
   sh scripts/build-sites.sh
   ```

3. جرّب النسخة المستقلة في المتصفح، ثم ارفع التغيير في فرع واطلب دمجه.

### رابط عام للزيارات

لنترك مع صاحب المحل رابطًا أو رمز QR، نرفع مجلد `demos/<name>-site` على استضافة ثابتة مجانية مثل GitHub Pages (المستودع عام) أو Netlify Drop أو Cloudflare Pages.

## طريقة العمل بيننا

- **المهام والخطة وقائمة المحلات في [صفحة المشروع على نوشن](https://app.notion.com/p/40c3a671129a810981a6d132d605a32f)** (تحتاج دعوة من صاحب الصفحة)؛ الكود والنماذج هنا.
- **لا نعمل على `main` مباشرة:** فرع لكل تغيير (`demo/restaurant-arabic-fixes` مثلًا)، ثم طلب دمج يراجعه الشريك الآخر.
- **رسائل الالتزام** قصيرة وتصف ما تغيّر ولماذا.
- **لا نرفع أبدًا:** بيانات عملاء حقيقية، أرقام جوالات حقيقية، مفاتيح API أو كلمات مرور، ملفات `.env`.
- **الأسعار في النماذج افتراضية.** عند تحديثها بأسعار محل حقيقي نكتب في رسالة الالتزام مصدرها (زيارة، تاريخ).
